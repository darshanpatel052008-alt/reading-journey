My Reading Journey

A multimodal website created for my WRD 103 course at DePaul University. This project transforms my literacy narrative into an interactive timeline, showing how my relationship with reading evolved from Spider-Man comics to novels, through a reading slump, and eventually rediscovering my love for reading.

Features
- Comic-book-inspired homepage
- Six-stage visual reading timeline with images
- Separate reflection page
- Responsive design for desktop and mobile

Built With
- HTML5
- CSS3
- GitHub Pages
